# Recambios y reparaciones · Mantenimiento Garcia de Pou

Web estática (GitHub Pages) con los datos, usuarios y adjuntos en Supabase (plan gratuito).

- `index.html` — la aplicación.
- `supa-shim.js` — conexión con Supabase (acceso con correo y contraseña).
- `config.js` — dirección del proyecto de Supabase y correos de administradores.
- `schema.sql` — estructura de la base de datos (ya aplicada).

Los usuarios se dan de alta en Supabase → Authentication → Users → Add user (marcar "Auto Confirm User").
